JARVIS UPGRADE — 27 OCTOBER 2026

The seven improvements are implemented and the updated assistant/Brain services
have been activated. The existing voice enrollment and account settings remain.

HOW TO USE THE CHANGES

1. Conversation
   More (...) > Voice health shows response timings and pacing controls.
   Defaults: 1.2 seconds to finish a phrase, 12-second follow-up window, and an
   85-character target for the first natural clause. Long first sentences can
   start speaking at a clause boundary. Later clauses retain normal buffering.
   Existing stop/barge-in behavior remains available. Timings record numbers,
   not speech/audio, and retain at most 60 observations per stage in memory.

2. Useful holographic panels
   Orbiting panels now contain notes, tasks, research citations, generated
   documents and project-session progress. Click one to expand its content.
   Say "show my tasks", "expand panel Alpha", "bring that closer", or
   "put that away". More > Holographic panels lists and restores dismissed panes.
   Source previews are bounded text; links and document opening are explicit.

3. Project continuity
   More > Resume project > Restore workspace, or say "resume Jarvis" or
   "resume Rocket Frontier". The workspace displays saved progress, attribution,
   unresolved items, next action, current Git evidence and relevant source files.
   Newer agent reports take precedence over older handoff summaries. Old plans
   are labeled for reconciliation. Restoring a project does not execute its plan.

4. Project-agent progress
   Tasks & agents displays observed tool milestones, current progress, changed
   files, reports, and Pause / Resume / Cancel controls for managed project agents.
   Pause interrupts the current agent turn; Resume starts another turn using its
   saved thread and task, with instructions to inspect existing work first.
   Completed side effects are not undone. A process restart marks unfinished
   sessions interrupted, allowing deliberate resumption. Stale activity is labeled.
   These controls cover named project sessions; standalone screen/terminal tasks
   retain their existing stop controls, not the new pause/resume interface.

5. Recovery
   A background monitor reconnects inactive/stalled microphone and speaker
   streams, with serialized retries and bounded backoff. Microphone-processing
   exceptions restart that processing loop. Voice health includes manual
   reconnect buttons and recovery status. VoiceStudio's existing bounded request
   timeout, reopen behavior and Kokoro fallback remain in use. Actions and AI
   requests are never automatically replayed. This does not recover arbitrary
   operating-system/driver hangs or every possible model failure.

6. GPU sharing
   Core graphics reduce to 24 fps and a maximum 512-pixel rendering target while
   speech recognition or synthesis is active, with a short hold to avoid flicker.
   Hidden pages stop the main rendering loop. The Quality selector offers
   Automatic, Cinematic, Balanced and Economy. GPU usage still depends on the
   display, other applications and the chosen model; this is not a GPU reservation.

7. Models and desktop orb
   The Core selector offers Holographic Core (purple), Jarvis Orbit (blue metal)
   and Fracture Sphere (orange fissures), inspired by the three reference designs.
   Each saves its color and quality settings. The purple core retains its nebula,
   orbiting particles/shooting stars and smoothly blended conversation motion.
   These are animated procedural interpretations, not pixel-identical replicas.
   Open the new "Jarvis Orb" desktop shortcut or More > Desktop orb.
   Drag its title strip; Expand opens the full workspace; Compact pins it again.
   Double-clicking the sphere also toggles size. The compact window has a command
   box and stays on top. pywebview 6.2.1 was installed in Jarvis's existing venv.
